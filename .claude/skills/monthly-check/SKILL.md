# 月1回の点検

## 手順
1. 全記事の外部リンク・内部リンクを確認し、切れているものを一覧にする。
2. `now-` の時事記事で、公開から3か月以上たったものを一覧にし、続報があるかWeb検索で確認する。更新候補と追記案を出す。
3. 価格や制度など、変わりやすい情報を含む記事を一覧にする。
4. アフィリエイトのリンク枠（`[リンク枠`）が残っている記事を一覧にする。
5. 日本語で「今月やるとよいこと」を優先順に5つまでまとめる。ファイルは勝手に直さず、オーナーの指示を待つ。
