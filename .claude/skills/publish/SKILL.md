# 公開の準備

対象: $ARGUMENTS（`_drafts/` 内のファイル名）

## 手順
1. 下書きに `[要確認` `[オーナーの体験` `[写真` `[リンク枠` の印が残っていないか確認する。残っていたら一覧を出して止まる。
2. ファイルを `articles/` に移す。
3. `index.html` に記事カードを追加する。時事なら「Now in Japan」の先頭、定番なら「Start here」の適切な位置。日付・カテゴリ・要約・読了時間を既存カードと同じ形で入れる。
4. 記事内とトップページのリンク切れがないか確認する。
5. 変更内容（diff）を日本語で要約してオーナーに見せ、ローカルで commit する。
6. **push はしない。** 「公開してOKなら push します」と確認し、オーナーがOKと言ったら push する。
