# SNS投稿セット

対象の記事: $ARGUMENTS（ファイル名かタイトル）

## 手順
1. 記事を読み、海外の読者が「へえ」と思うポイントを3つ抜き出す。
2. 次を英語で作り `_drafts/sns/<slug>.md` に保存する:
   - **Threads**: 3投稿（それぞれ1つのポイント。最後の1つに記事へのリンク）
   - **Instagram**: キャプション1つ（冒頭1行で引きつける、ハッシュタグ5〜10個）
   - **TikTok / Reels**: 30秒の台本（0〜3秒のつかみ、本題、最後に「詳しくはプロフィールのリンク」）
   - 撮影するとよいカットの一覧
3. 記事にない事実は足さない。誇張しない。
4. 日本語で、どの投稿をどの順番で出すとよいかを一言添える。
