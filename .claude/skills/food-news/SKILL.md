# 今週の食ニュース

対象期間: $ARGUMENTS（指定がなければ直近2週間）

## 手順
1. `articles/` の `now-` で始まる記事を確認し、すでに扱った話題を把握する。
2. Web検索で、日本の食に関するニュースを探す（米・野菜などの価格、コンビニ・スーパーの新しい動き、制度の変更、季節の話題、京都の食の話題など）。
3. 海外の読者にとって「知ると日本の食卓や買い物が理解できる」話題を5つ選ぶ。
4. 日本語で一覧にする。それぞれに:
   - 話題の要点（2〜3行）と出典URL
   - 海外の読者向けの切り口（なぜ面白いか）
   - 関連する既存記事
   - オーナーの体験が活きそうなポイント
5. オーナーが選んだら、`new-article` の手順で下書きを作る。
