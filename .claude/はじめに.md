# Itadakimasu AI運用キット — はじめに

## 入れ方（最初に1回だけ）※ 2026-10-07 セットアップ済み
1. Itadakimasu のリポジトリのフォルダ（index.html がある場所）を開く。
2. このキットの `CLAUDE.md` と `.claude` フォルダを、そのままコピーして入れる。
3. そのフォルダで Claude Code を起動して、こう頼む:
   「`_drafts/` を .gitignore に追加して。あと、このサイトが Jekyll かどうかも確認して教えて」

## 毎日の使い方（目安30分〜1時間）
| やりたいこと | Claude Codeに打つもの |
|---|---|
| 時事ネタを探す | `/food-news` |
| 記事の下書き | `/new-article 京都の生麩` |
| メモから記事 | `/new-article` のあとに、スマホの音声入力で話したメモを貼る |
| SNS投稿を作る | `/sns-posts mentsuyu` |
| 公開の準備 | `/publish now-rice-prices-2026.html` |
| 月1回の点検 | `/monthly-check` |

## ひーちゃんがやること
- 体験談を話す（スマホの音声入力で5分）
- 写真を撮る
- 下書きの `[要確認]` `[オーナーの体験]` `[写真]` を埋める
- 「公開してOK」を出す

## 最初に1つだけ決めておくこと
About と Work with me には「本人が書いて翻訳している」とあります。AIを下書きや翻訳の補助に使うなら、表記を実態に合わせて直しておきましょう。翻訳の仕事を依頼する人にとっても大事な情報です。
Claude Code に「AIの使い方の表記を About と Work with me に合わせて直す案を出して」と頼めば、案を作ってくれます。
